# 06 聲音設計

聲音的工作是讓觀眾**感覺**到故事的起伏，同時不搶旁白。

## 1. 配音

- 先只產生第一場（`tts.py --only s01`）請使用者聽：口音、速度、情緒對不對。
- 口音：要台灣口音，`style` 一定要明寫「台灣口音的華語」。
- 念錯：用 `["念法", "顯示"]`；英文縮寫逐字母加空格。
- 太平：每場 `dir` 寫具體的差異（懸念、轉亮、加重、放慢）。
- 長度：`align_timeline.py --target` 自動壓到目標長度（見 05）。

## 2. 配樂的情緒曲線

先畫出故事的情緒曲線，音樂跟著它走：

| 故事階段 | 音樂可以怎麼做 |
|---|---|
| 壓抑、提問 | 只有一層旋律或氛圍；用低通濾波讓聲音「悶住」 |
| 轉折、登場 | 濾波打開、低音與鼓同時進來；強拍落在畫面的關鍵瞬間 |
| 推進、展示 | 穩定的節奏；中段加一層樂器增加推進感 |
| 金句、重點 | 抽掉鼓或降低音量 1～2 小節，讓那句話被聽見 |
| 收尾 | 先退節奏，留旋律，淡出 |

`music.py` 用 loop 編排：所有軌道的音量（gain）與低通濾波（lowpass）都是 `[時間, 值]` 的折線，時間用運算式綁旁白（`S(1)+0.1`、`L(4,2)+2*BAR`、`END-3`）；`anchor` 讓某一小節的強拍對準指定時間。

```jsonc
{ "bpm": 100, "anchor": "<產品登場的時間>", "peak": 0.89,
  "tracks": [ { "file": "loops/xxx.wav", "gain": [[0,0],["S(1)",0.7],["END",0]], "lowpass": [[0,500],["S(1)",18000]] } ] }
```

## 3. 素材來源

- **Apple Loops（Mac 內建 GarageBand）**：約 1,700 個 loop，可免版稅用在自己的影片作品中（不可單獨散布 loop 檔）。`apple_loops.py list / beats / convert`。
  - 同一「家族」（名稱前綴相同，例如 `XXX Bass`、`XXX Synth`）是同 BPM、同調，可直接疊。
  - 從長度推 BPM：9.6 秒 = 100 BPM 四小節、8.0 秒 = 120 BPM 四小節；鼓組長度要是旋律的 1/2 或相同。
- 使用者自己有授權的音樂：music.json 只放一軌，用 gain 折線做起落。
- 依觀眾選曲風：企業／科技偏平穩、低刺激；新創偏輕快；教育偏溫暖原聲。避開有人聲的 loop（會跟旁白打架）。
- 無法試聽時：用 numpy 計算 RMS 與頻譜重心（重心越高越刺耳）輔助挑選，**最後一定請使用者聽**。

## 4. 音效

`sfx.py` 程式合成（無版權問題）：

| 類型 | 用途 |
|---|---|
| whoosh | 主要轉場；峰值對準切換點（`offset` 約 -0.25） |
| boom | 一支片 2～4 次的重擊：登場、片名、Logo |
| tick | 小元素逐一出現 |
| riser | 大轉折前的上升（選用） |

少即是多：只放在真正的轉折點。每個動作都配音效會很吵、很廉價。

## 5. 混音

`mix.py`：旁白（高通＋壓縮）、音樂（側鏈壓縮，旁白出現時自動降低）、音效 → loudnorm。
- `--music`：旁白密集 0.25、旁白稀疏 0.35。
- `--lufs`：網路 -14～-16；會議室投影 -16～-18。
- 交付前：檢查響度、開頭結尾沒有爆音；**請使用者親自聽**。
