# 檢查清單

## A. 腳本（給使用者確認前）
- [ ] 第一場 3 秒內有痛點或反差
- [ ] 每句 8～24 字、台灣用語、英文縮寫有念法修正
- [ ] 每句都寫了對應畫面，且畫面能從產品實際拍到
- [ ] 模擬資料、示範係數、未來功能都有誠實標示
- [ ] 首尾呼應；片尾有署名與行動呼籲
- [ ] 總字數符合長度（90 秒 ≈ 330～360 字）

## B. 鏡頭（contact_sheet.py clips）
- [ ] 每個鏡頭的關鍵動作都有發生（log 沒有「找不到按鈕文字」）
- [ ] 環繞起點、終點都好看，沒有轉到背面或穿模
- [ ] 格數夠長（台詞長度 + 2 秒）
- [ ] 沒有拍到開發者工具、錯誤訊息、私人資料

## C. 動畫（render.py --sheet，逐張看）
- [ ] 每張的畫面跟字幕內容對得上
- [ ] 上一個鏡頭有隱藏，沒有蓋住後面的大字或 Logo
- [ ] 卡片、標籤在預期位置（沒有被 `.glass` 的 relative 推走）
- [ ] 文字沒有超出框、沒有壓在 3D 主體或亮色地板上看不清
- [ ] 字幕區沒有被擋
- [ ] 推鏡後重點面板沒有被切掉
- [ ] 產品畫面出現期間有「展示畫面・模擬資料」
- [ ] 片尾 Logo 完整出現並停留 2 秒以上

## D. 聲音
- [ ] 總長符合目標（±1 秒）
- [ ] 音樂強拍落在產品登場、金句時鼓有抽掉
- [ ] 整體響度 -14～-16 LUFS
- [ ] **請使用者親自聽**：口音、念錯字、音樂與旁白比例

## E. 成片（contact_sheet.py video --every 4）
- [ ] 沒有黑畫面、閃爍、上一格殘影
- [ ] 解析度 1920×1080、30fps、H.264 + AAC
- [ ] 檔案大小符合傳送需求（必要時用 `--max-mb`）
