# 07 審查：用觀眾的眼睛看

## 1. 方法

1. **總覽圖逐張看**（`render.py --sheet`）：每張圖遮住字幕，只看畫面——能猜出這句在講什麼嗎？猜不出來，畫面沒有在「演」台詞。
2. **轉場瞬間抽查**（`--stills` 指定轉場中間的秒數）：有沒有黑畫面、空白、上一個鏡頭殘留。
3. **縮小看**：把總覽圖縮到手機大小，重點還看得清楚嗎？
4. **成片每 4 秒抽一格**（`contact_sheet.py video --every 4`）。
5. **自問三題**：觀眾 3 秒內知道這支片在講什麼嗎？看完記得那一句價值主張嗎？有沒有任何一句話會讓懂行的人覺得誇大？

## 2. 檢查清單

### 故事
- [ ] 前 3 秒有抓住注意力的東西
- [ ] 有一條主線；每個 beat 都在支撐價值主張
- [ ] 情緒有起伏；money shot 在高點
- [ ] 誠實標示（模擬資料、示範參數、路線圖）

### 鏡頭
- [ ] 每個關鍵動作都發生了，且對上台詞
- [ ] 運鏡起點與終點構圖良好
- [ ] 沒有拍到錯誤訊息、開發工具、私人資料

### 畫面
- [ ] 每句話都有畫面在演
- [ ] 同時最多 3 個焦點
- [ ] 文字有底、不壓產品主體、不出框、不擋字幕
- [ ] 推鏡後目標沒有被切掉
- [ ] 視覺跟產品一致（色票、語意色、字型）
- [ ] 沒有每場都用同一招
- [ ] 前一個鏡頭有隱藏；Logo 完整出現並停留

### 聲音
- [ ] 長度符合目標
- [ ] 音樂起落跟故事一致、金句有讓出空間
- [ ] 響度 -14～-16 LUFS；沒有爆音
- [ ] 使用者已親自聽過

### 檔案
- [ ] 1920×1080、30fps、H.264 + AAC
- [ ] 大小符合傳送方式（必要時 `mix.py --max-mb`）
