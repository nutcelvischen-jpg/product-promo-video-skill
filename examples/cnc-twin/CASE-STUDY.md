# 案例研究：CNC 工廠數位孿生介紹影片

> 這份文件記錄「為什麼這樣決定」。請學的是推理過程，不是場景、台詞、顏色本身。
> 換一個產品，答案幾乎都會不一樣——下面每一段最後都寫了「換成別的產品會怎樣」。

**產品**：Three.js CNC 工廠數位孿生（6～12 台 CNC、場外太陽能、生產／電力／碳排圖層、情境模擬、新增裝置），資料為模擬。
**需求**：90 秒、華語、給企業客戶、片尾署名 ICMA Lab。
**成品**：90.6 秒，8 場，10 個鏡頭。

---

## 1. 理解產品時發現了什麼

| 觀察 | 判斷 | 行動 |
|---|---|---|
| 電力／碳排圖層只是 3D 機台輕微變色，縮小後看不出來 | 後製補不了 | 請使用者先改程式：圖層用明顯的藍／橘紅，能源粒子加粗加亮 |
| 「廠房內部」鏡頭只拉近一點 | 後製補得了，但改了更有張力 | 使用者改成降到走道平視 |
| 情境切換時太陽能 27→8 kW、購電 24→43 kW、趨勢圖轉折 | 這是「一個動作引發大量連動」 | 選為 money shot 之一 |
| 數字小（KPI 只占畫面一小塊） | 推鏡即可 | 拍整個介面，動畫裡放大 |
| 有「模擬資料」標籤、碳排係數是示範值 | 誠實標示 | 影片常駐「展示畫面・模擬資料」、公式卡註明示範係數 |

**換成別的產品**：先找出你的產品「哪個功能縮小後看不出來」「哪個動作會引發最多連動」。

## 2. 故事的推理

- **觀眾**是企業決策者 → 在意成本、風險、管理可視性，不在意 Three.js。
- **價值主張**：「看得見，才管得好」——把工廠裡看不見的電力與碳排變成看得見。
- **結構**：觀眾（工廠管理者）本來就有「電費只看得到總數」的痛 → 選「問題 → 解法」為主線，中段用「情境模擬」放大決策價值（數位孿生最大的差異化）。
- **首尾呼應**：開場大字「看不見，」→ 結尾「看得見，才管得好。」
- **台詞取捨**：原本想講 CSV 匯出、暫停、模擬速度，但這些對決策者不是價值，刪掉；保留「新增機台」是因為它回答了「產線擴充怎麼辦」的導入疑慮。
- **路線圖**：IoT 串接還沒做，所以只放在「下一步」，用架構圖表現。
- **開場帳單金額**是戲劇化數字，交付時有提醒使用者。

**換成別的產品**：如果你的產品是給學生用的學習工具，痛點、結構、語氣都會完全不同（可能是「成果先行」或「一個角色的一天」），不會有帳單、不會有 KPI。

## 3. 鏡頭的推理

| 台詞要傳達 | 為什麼選這個鏡頭 |
|---|---|
| 產品登場的氣勢 | 3D 全螢幕環繞（cine）：只有 3D 才有「整座工廠」的量感 |
| 「狀態、進度、產量即時同步」 | 整個介面放進傾斜的瀏覽器框：讓觀眾知道這是一個完整的系統 |
| 「3D 廠區即時同步」 | 降到走道平視的內部鏡頭：從管理儀表板跳到「身歷其境」，製造落差 |
| 「點一下，看到轉速、功率、用電」 | UI 鏡頭，第 20 格點 CNC-03，再推鏡到右側細節面板 |
| 「電從哪裡來、流向哪裡」 | 電力圖層 cine＋圖例：能源流向只有 3D 粒子表現得出來 |
| 情境（雲層、故障） | UI 鏡頭，第 30 格按情境，推鏡到變化的數字 |
| 「新增機台，自動排位」 | UI 鏡頭，逐字輸入名稱、按新增，3D 立刻多一台 |

動作都放在第 20～30 格，動畫用 `clip(sel, T - F/30, ...)` 對到問句講完的瞬間。

**換成別的產品**：沒有 3D 的產品，就沒有 cine 鏡頭；「氣勢」可能改用介面的整體展開、或資料視覺化的動態。

## 4. 視覺的推理

- 顏色全部來自產品：深青底、薄荷綠主色、琥珀＝太陽能、藍＝電力、珊瑚紅＝故障／碳排。影片裡的標籤顏色跟產品圖層的意義一致，觀眾不用重新學。
- 字型用產品的 Manrope。
- 技巧依問題選：
  - 「該看哪裡」→ 推鏡＋左側壓暗＋標註（細節面板）
  - 「怎麼運作」→ 公式卡（太陽能平衡、碳排計算）、架構圖（IoT）
  - 「這很重要」→ 暗場大字（先模擬，再決策）
  - 「這是真的系統」→ 瀏覽器框
- 踩過的坑：公式卡因為 `.glass` 的 `position:relative` 跑出畫面；文字壓在亮色 3D 地板上看不清，改成深色卡片。

**換成別的產品**：你的產品色票、語意色不同，標籤、卡片、強調色都跟著換；技巧依你的產品「哪裡看不懂」來選。

## 5. 聲音的推理

- 聲音：Leda、科技發表會旁白的沉穩語氣（企業觀眾）。
- TTS 比估計長 6%：`align_timeline.py --target 90` 加速 1.06 倍。
- 配樂：Apple Loops Chillwave 的「Forward Progress」家族（平穩、現代、不搶旁白）＋同 BPM 的鼓組。
  - 開場只有濾波過的旋律（壓抑）→ 產品登場時濾波打開、鼓和貝斯進來（anchor 對準登場）→「先模擬，再決策」抽鼓兩小節 → 結尾只留旋律淡出。
- 音效：11 個轉場 whoosh、3 個 boom（登場、片名、Logo）、3 個 tick（問題膠囊）。

**換成別的產品**：給學生的影片可以用更輕快的曲風、更活潑的聲音；情緒曲線跟著你的故事畫。
